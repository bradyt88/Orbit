# Orbit Brain Image Upload

Upload the replacement brain artwork into this folder.

**Preferred filename:** `orbit-brain.png` (or `orbit-brain.webp` if that is the format you have).

Use a high-resolution image with a transparent background if possible. Keep the image centered with a little space around the brain. Do not delete this README; it keeps the upload folder visible in GitHub.

Once the image is uploaded, tell ChatGPT the filename you used. Orbit's code can then be updated to display the new image and tested through GitHub Pages.
