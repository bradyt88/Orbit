# Orbit Family Tree artwork

Upload the people-free Family Tree background image into this folder as:

`family-tree-background.png`

Expected path used by the app:
`/Orbit/images/family-tree/family-tree-background.png`

Keep the artwork as a background only. Family member portraits, relationship branches, labels, zoom/pan, and full-screen controls will be rendered separately by the app so they remain interactive.
